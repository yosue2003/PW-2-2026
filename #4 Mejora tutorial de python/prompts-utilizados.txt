2. PROMPT DETALLADO DE DESARROLLO

"Crea un documento web educativo en español para principiantes: amplía un tutorial de Python siguiendo los temas de Python for Everybody, de Charles R. Severance, con ejemplos originales y explicación de cada bloque. Usa W3.CSS y CSS propio. Diseña mobile first para móvil vertical; añade ajustes para móvil horizontal y luego laptop. Incluye una sección que explique el proceso con IA, las herramientas utilizadas, las fuentes consultadas y una explicación del código generado. Usa HTML semántico, accesibilidad básica, navegación por secciones y deja un campo editable para el nombre del estudiante."

¿QUÉ APORTÓ ESTE PROMPT?
- Definió el público y el idioma.
- Organizó el contenido de Python en ejemplos cortos y explicados.
- Separó la estructura HTML de la presentación CSS.
- Especificó el orden responsive: móvil vertical, móvil horizontal y laptop.
- Pidió accesibilidad básica, navegación interna, fuentes y transparencia sobre el uso de IA.

3. INSTRUCCIÓN POSTERIOR PARA QUITAR SECCIONES

"elimina GitHub Pages y Moodle todo ellopublicar el sitio y presentar el proceso"

Se eliminó de la página el contenido de publicación y entrega: la sección de GitHub Pages, Moodle, el video, su título sugerido y el espacio para pegar su enlace. Se conservó la explicación de cómo se construyó la página con IA y cómo leer su código.
