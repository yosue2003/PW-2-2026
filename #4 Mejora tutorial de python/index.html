01

FUNDAMENTOS

Python, desde el principio

Python es un lenguaje legible y versátil. En esta ruta aprenderás a guardar datos, tomar decisiones, repetir instrucciones, organizar código y trabajar con colecciones.

La idea clave

Predice qué hará un ejemplo, ejecútalo y cambia una parte. Comprender el resultado importa más que memorizar la sintaxis.

1

Mostrar información y comentarios

print() muestra un resultado. El texto después de # es un comentario que Python ignora.

# La función print muestra un mensaje
print("Estoy aprendiendo Python")
print("Segunda línea")

Explicación: cada llamada escribe su argumento y termina la línea. Las comillas delimitan texto.

2

Variables y tipos de datos

Una variable asocia un nombre con un valor. Tipos básicos: texto (str), entero (int), decimal (float) y verdadero/falso (bool).

nombre = "Lucía"       # str
edad = 20              # int
estatura = 1.65       # float
estudia = True         # bool
print(nombre, edad)

Explicación: el signo = asigna el valor. Usa nombres que describan el dato.

3

Entrada, conversión y operaciones

input() recibe texto. Para operar con un número, convierte la entrada con int() o float().

edad_texto = input("¿Cuántos años tienes? ")
edad = int(edad_texto)
proximo_anio = edad + 1
print("El próximo año tendrás", proximo_anio)

Operadores: + suma, - resta, * multiplica, / divide, // división entera, % residuo y ** potencia.

4

Decisiones con if, elif y else

Una condición ejecuta un bloque según se cumpla o no. La indentación indica qué líneas pertenecen al bloque.

nota = 82
if nota >= 90:
    resultado = "Excelente"
elif nota >= 60:
    resultado = "Aprobado"
else:
    resultado = "Sigue practicando"
print(resultado)

Explicación: se revisan las condiciones en orden y se ejecuta la primera verdadera. Los dos puntos abren el bloque.

5

Repeticiones con for y while

Usa for para recorrer una secuencia y while para repetir mientras una condición sea verdadera.

for numero in range(1, 4):
    print("Vuelta", numero)

contador = 3
while contador > 0:
    print(contador)
    contador = contador - 1

Explicación: range(1, 4) produce 1, 2 y 3; el límite final no se incluye. El contador cambia para que el ciclo termine.

6

Funciones: reutilizar una tarea

Una función reúne instrucciones. Sus parámetros reciben datos y return devuelve un resultado.

def saludar(nombre):
    mensaje = "Hola, " + nombre
    return mensaje

saludo = saludar("Lucía")
print(saludo)

Explicación: def define la función; al llamarla, el argumento se recibe en nombre y el resultado vuelve a saludo.

7

Cadenas y listas

Una cadena contiene caracteres. Una lista guarda varios valores en orden y puede modificarse.

curso = "Python para todos"
print(curso.lower())
print(curso.find("todos"))

temas = ["variables", "condiciones"]
temas.append("funciones")
for tema in temas:
    print(tema)

Explicación: lower() convierte a minúsculas, find() busca una posición y append() agrega al final. Los índices empiezan en cero.

8

Diccionarios y errores

Un diccionario relaciona claves y valores. try/except permite responder a entradas que no se pueden convertir.

puntaje = {"Ana": 9, "Luis": 7}
print(puntaje["Ana"])

try:
    cantidad = int(input("Cantidad: "))
except ValueError:
    print("Escribe un número entero.")

Explicación: puntaje["Ana"] busca el valor de esa clave. Si la entrada no es un entero, se ejecuta el bloque except.

02

ESTILOS Y COMPONENTES

W3.CSS en práctica

W3.CSS ofrece clases listas para organizar contenido, dar espacio, crear tarjetas y diseñar páginas adaptables. Se carga en el <head> y sus clases se aplican a elementos HTML.

ESTRUCTURA

Contenedores

w3-container agrega espacio interior. w3-row-padding organiza columnas con separación.

COLOR

Utilidades

w3-blue aplica color, w3-text-white cambia el texto y w3-center lo centra.

ADAPTACIÓN

Columnas

w3-col, l6 y m6 definen anchos por dispositivo. El proyecto también usa CSS propio.

Cómo se carga en este proyecto

<!-- Dentro de <head> -->
<link rel="stylesheet" href="https://www.w3schools.com/w3css/5/w3.css">
<link rel="stylesheet" href="styles.css">

W3.CSS aporta clases utilitarias. styles.css controla la identidad visual, el menú, las tarjetas y los ajustes por pantalla. Al cargarse después, las reglas propias pueden adaptar esos estilos.

03

DISEÑO ADAPTABLE

Mobile first: teléfono antes que laptop

El CSS base está diseñado para un móvil angosto en orientación vertical. Las media queries añaden ajustes para teléfono horizontal y, después, laptop.

01

Teléfono vertical · base

Una columna, texto legible, botones cómodos y bloques de código con desplazamiento horizontal.

estilos base, sin media query
02

Teléfono horizontal · hasta 767 px

La portada usa dos columnas cuando hay espacio horizontal suficiente.

@media (orientation: landscape) and (max-width: 767px)
03

Laptop · desde 900 px

Aparece una tabla de contenidos lateral y se amplían márgenes y columnas.

@media (min-width: 900px)
La etiqueta viewport

<meta name="viewport" content="width=device-width, initial-scale=1"> hace que el navegador use el ancho real del dispositivo para presentar la página.

Los puntos de corte son decisiones de este proyecto; conviene revisar el contenido en varios tamaños y ajustar el diseño a lo que se necesite.

TRANSPARENCIA

Cómo se construyó con ayuda de IA

La IA sirve como asistente para planificar, proponer ejemplos iniciales y revisar explicaciones. Quien estudia debe leer el código, comprobarlo y explicarlo con sus palabras.

Herramientas de este documento

Se usó OpenAI Codex como asistente de IA para redactar y organizar index.html y styles.css. La página combina HTML semántico, W3.CSS 5 y CSS propio. Las fuentes didácticas están enlazadas al final.

Cómo leer el código del sitio

HTML

Contenido y estructura

<header> contiene la identidad y navegación; <main> agrupa el contenido; cada <section> representa una lección con identificador para los enlaces; <article> separa ejemplos; y <footer> cierra la página.

CSS

Presentación y tamaños

styles.css define colores, tipografía, tarjetas y espaciados. Los estilos iniciales forman la versión móvil vertical; las reglas @media adaptan la portada y las columnas a móvil horizontal y laptop.

W3

Hoja externa

El primer enlace del <head> carga W3.CSS y el segundo, los ajustes propios. Esta página usa principalmente reglas propias y explica clases W3.CSS comunes para que puedas incorporarlas.
